# Accountant Workflow

Accountant mapping:
- Maja -> Tiara.
- Cemplang -> Uya.

Flow:
1. Actual usage finalized.
2. Claim/reimbursement price finalized separately from vendor cost.
3. Generate accountant Excel snapshot from final calculator/costing data.
4. Send Excel to the site accountant.
5. Receive accountant invoice + invoice number.
6. Create BGN maker.
7. Send maker/approval list to kitchen head.
8. Approval.
9. BGN funds received by Yayasan and/or Koperasi.
10. Settlement to BCA Operational.

Accountant evidence and generated files should be stored in Google Drive raw evidence, while workflow state is stored in PostgreSQL.
